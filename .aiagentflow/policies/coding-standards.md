# Padrões de Codificação

Siga rigorosamente as regras deste documento.

## Geral
- Escreva código limpo e legível na linguagem configurada do projeto
- Use nomes significativos para variáveis e funções
- Mantenha funções pequenas e focadas (responsabilidade única)
- Trate erros explicitamente — nunca engula exceções
- Siga padrões idiomáticos para a linguagem e framework do projeto

## Qualidade de Código
- Use o sistema de tipos da linguagem quando disponível
- Prefira tipos explícitos para assinaturas de funções
- Siga as convenções e o estilo estabelecidos do projeto

## Testes
- Toda função pública deve ter testes
- Teste comportamento, não implementação
- Use nomes de testes descritivos
- Use o framework de testes configurado do projeto

## Git
- Nunca realize commits, pull ou push.
- Nunca crie ou remova branchs locais ou remotas.
