# Descrição da atividade
Alguns dados como os de links de contato dispostos na página se repetem no html. O objetivo desta atividade será concentrar esses dados em um objeto tornando eles reutizáveis

## Ações a serem executadas.

### Ações para o objeto
- Crie um objeto, no padrão chave e valor, com o objetivo de guardar informações pessoais
- O objeto deve conter os dados: Nome, cidade/estado, email e um objeto contendo os links de Whatsapp, Linkedin, Github e Google maps
- Os dados do objetos devem ser os mesmos contidos na página
- Substitua os textos na página pelos respectivos dados do objeto
- Para os links de email (mailto) cocatene o email do objeto ao link

### Ações para os botões no header
- Separe os botões de Whatsapp e Linkedin do header em elementos html distintos
- Use os dados do objeto nos links dos botões
- Remova a constante ```contacts``` utilizada para renderizar estes botões
