# Descrição da atividade
Você fará ajustes de otimização de componentes. A aplicação tem elementos html que possuem características de estilização que se repetem e podem ser transformados em componentes reutilizáveis

## Ações a serem executadas.
- O template a ser otimizado é o ```src/App.vue```
- Crie um component baseado nos elementos ```section``` de classe ```class="py-8 md:py-10 lg:py-16"``` e ajuste o uso deles no template principal para utilizar o novo componente.
- Faça o mesmo para os títulos e parágrafos deixando o componente de cada um deles apenas com as classes que definem aspectos visuais definindo as classes de espaçamento no uso de cada componente no template principal de acordo com o local em que então dispostos.
