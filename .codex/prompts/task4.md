# Descrição da atividade
O objetivo desta atividade é fazer ajustes no componente principal ```src/App.vue``` para reduzir o seu tamanho organizando código e estrutura.

## Ações a serem executadas.

### Container
- O elemento alvo deste ajuste é o de classe ```.container```
- Crie um novo componente para o elemento alvo
- O novo componente deve ter apenas as classes de uso comum entre os elementos alvo
- Substitua o uso do elemento alvo no componente principal pelo novo componente adicionando as classes auxiliares de cada elemento substituido

### Header
- Crie um novo componente para o elemento ```header```
- Substitua o header do componente principal pelo novo componente header
- Os dados do menu de navegação devem ficar no novo componente
- Os dados de informação pessoal devem ser passados por referência

### Footer
- Crie um novo componente para o elemento ```footer```
- Substitua o footer do componente principal pelo novo componente footer
- Os dados de informação pessoal devem ser passados por referência
